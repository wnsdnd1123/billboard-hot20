개인정보처리방침

본 앱은 운영자 본인의 계정에 사용하는 개인용 플레이리스트 자동화 도구입니다.

처리하는 정보와 목적

사용자가 승인한 Google OAuth 인증 정보와 지정한 YouTube Music 플레이리스트의 제목, 곡 목록 및 곡 식별자를 처리합니다. 목적은 Billboard Hot 100 상위 20곡에 맞춰 해당 플레이리스트를 갱신하는 것입니다.

저장 및 접근

장기 인증 정보는 운영자가 GitHub Actions Secrets에 저장합니다. 실행 중 GitHub 실행 환경의 메모리에서 인증 정보를 사용합니다. 설정을 위해 Google Colab을 사용하는 경우 업로드한 인증 파일과 발급 토큰이 그 런타임 및 저장한 노트북 출력에 남을 수 있습니다. 운영자는 설정 후 출력과 런타임을 삭제해야 합니다.

곡 목록, 선택한 음원, 실행 전후 플레이리스트 정보는 실행 로그와 GitHub Actions 아티팩트에 기록될 수 있습니다. 아티팩트 보관 기간은 14일입니다. 로그와 아티팩트의 접근 범위 및 보관은 GitHub의 저장소 공개 범위와 접근 정책에 따릅니다.

서비스 제공자 및 이용 제한

인증과 음원 검색에는 Google/YouTube 서비스를, 예약 실행과 비밀값 보관에는 GitHub를 사용합니다. 해당 제공자의 개인정보처리방침도 적용됩니다. 본 앱은 데이터를 판매하거나 광고 목적으로 사용하지 않으며 AI 모델 학습에 사용하지 않습니다.

철회 및 삭제

Google 계정의 보안 설정에서 앱 접근을 철회할 수 있습니다. 운영자는 GitHub의 Secrets, 실행 기록, 아티팩트와 저장한 인증 파일 및 노트북을 삭제할 수 있습니다. 접근을 철회하거나 필요한 Secrets를 삭제하면 자동 갱신이 중단됩니다.

문의

운영 GitHub 저장소를 통해 문의할 수 있습니다. 인증 정보와 토큰을 공개 이슈에 게시하지 마세요.
