이용약관

본 프로그램은 운영자 본인의 YouTube Music 플레이리스트를 관리하는 개인용 소프트웨어입니다.

자동 변경

계정 소유자가 인증하고 예약 실행을 설정하면 지정한 플레이리스트의 곡을 추가·삭제하고 순서를 바꿀 수 있습니다. 음원 검색 결과에 따라 기존 곡의 음원 버전이 교체될 수 있습니다.

제약

차트 데이터, 음원 검색 및 외부 서비스의 변경이나 장애로 실행이 중단되거나 곡 선택이 부정확할 수 있습니다. API 편집은 일괄 트랜잭션이 아니므로 실패 시 일부 변경이 남을 수 있습니다. 운영자는 실행 기록과 백업을 확인하고 필요하면 재실행해야 합니다.

중단

GitHub Actions 워크플로를 비활성화하거나 Google 계정에서 인증을 철회하면 자동 실행을 중단할 수 있습니다.

외부 서비스

Google, YouTube, GitHub 및 데이터 제공자의 관련 약관이 적용됩니다. 본 프로그램은 이들 서비스 또는 Billboard의 공식 서비스가 아닙니다.
